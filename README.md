# DigitalEnryu

I build and operate automated systems, and then I write down what actually happened.

This account is an archive rather than a workshop. Each repository here is a project that genuinely
ran, produced real numbers, and was retired deliberately. They are published as case studies, not as
maintained software.

That means each one carries the same three things:

- **The architecture**, and the reasoning behind the parts that were not obvious.
- **The results**, with the real figures rather than the flattering ones.
- **The failure log**, which is usually the most useful document in the repository.

Projects are added here as they reach end of life. Nothing is published while it is still running.
